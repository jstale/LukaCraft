# LukaCraft

A small Minecraft-style voxel game that runs in the browser (three.js, no build step).

## Run

```
npm install
npm start          # http://localhost:8080
```

## Features

- Infinite, seeded procedural world in 16×16×96 chunks: oceans, beaches, plains, forests (oak + birch), deserts (cacti) and snowy mountains, plus caves and ore veins.
- Blocks: grass, dirt, stone, cobblestone, sand, gravel, snow, water, oak/birch logs and leaves, planks, crafting table, glass, stone bricks, coal/copper/iron/gold ore, bedrock, cactus.
- Hold left click to mine (crack animation, tool speed and tier rules), right click to place blocks.
- Crafting (press **E**): planks, sticks, crafting table, smelting ores into ingots (raw ore + coal), and pickaxes, axes and shovels in wood, stone, copper, iron and gold. Tools have durability. Tool recipes need a crafting table nearby.
- Progression: wood → stone pickaxe (mines copper) → copper pickaxe (iron) → iron pickaxe (gold).
- Autosaves your edits, inventory and position to localStorage.

## Controls

WASD move · mouse look · Space jump/swim · Shift sprint · 1–9/wheel hotbar · E inventory · F fly · F3 debug · +/− render distance · Esc pause

## Textures

Every texture is generated by `tools/gen-textures.mjs` (no external assets):

```
npm run textures   # writes textures/{blocks,items,misc}/*.png and textures/preview.png
```

## Tests

```
npm test           # unit tests: world gen, mining rules, inventory/crafting, mesher
npm run test:e2e   # plays the game in headless Chrome and saves screenshots to tests/screenshots
```
